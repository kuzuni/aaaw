# `data/` — 게임 수치 정본 내보내기 (유니티 이식용)

> **유니티(C#) 쪽은 이 폴더만 읽는다. 여기 있는 JSON 을 손으로 고치지 말 것 —
> 수치를 바꾸려면 `sim.js`(일부는 `index.html`)를 고치고 아래 명령으로 다시 뽑는다.**
> 주인 지시 (2026-09-06 KST 00:0X · 작업 T170): «게임 수치를 JSON 으로 내보내는 도구 — 유니티는 코드가
> 아니라 수치만 가져간다. 원본이 바뀌면 다시 뽑는다.»

```bash
node tools/exportData.js           # data/*.json 을 전부 다시 쓴다
node tools/exportData.js --check   # 다시 뽑아 커밋본과 비교 (exit 1 = 드리프트)
node tools/verifyExportData.js     # 게이트 (드리프트 + 스키마 + 두 엔진 대조 + 음성)
```

**엔진 수치를 바꾼 커밋은 `data/` 를 같이 담아야 한다** (ROUTINE §1 절대 규칙). 안 담으면
`verifyExportData` 가 빨개진다 — 그것이 이 폴더가 낡지 않게 하는 유일한 장치다.

## 읽는 법

- **단위** — 길이는 **월드 px**(카메라 줌과 무관한 게임 좌표) · 시간은 **초** · 확률은 문맥에 따라
  **0~1 소수**(`ENEMY_EVADE 0.10`·`PERK_*_CH`)와 **퍼센트 포인트**(`gachaRate` · 치확 `+5`)가 섞여 있다 —
  각 값의 이름과 `_note` 를 볼 것. 나머지는 **배수(무단위)**.
- **`_source`** — 그 파일을 뽑은 원본의 **git blob SHA**(`git hash-object sim.js` 와 같은 값). 커밋 SHA 가
  아니라 **내용 해시**다: 커밋 SHA 로 두면 sim.js 와 무관한 커밋마다 `--check` 가 빨개져 게이트가 못 쓰게 된다.
  ⚑ 주인 지시문은 «커밋 SHA» 라 적혀 있다 — 다르게 원하시면 한 줄로 정정.
- **`_generatedAt`** — 뽑은 시각. `--check` 는 이 한 줄만 같은 자리에 놓고 비교한다(시각은 내용이 아니다).
- **숫자는 엔진 그대로**다 — 반올림·재해석하지 않았다. `enemies.json` 의 적 HP/DMG 는 엔진이 `Math.round`
  한 **뒤**의 정수이므로 유니티에서 다시 곱하지 말고 그대로 쓴다.
- **배열 순서 = 엔진 순서**다. 특전의 `order`, 장비 옵션의 `slot`(1~7), 등급 인덱스
  (0 일반 · 1 희귀 · 2 전설 · 3 신화)는 전부 엔진 인덱스와 같다. **«영웅» 등급은 없다**(T153 폐지).
- **`effect`** — 특전·장비 옵션의 효과는 문구를 파싱한 것이 아니라 실제 `ap()` 를 탐침 플레이어에 적용해
  뽑은 **동작 실측**이다. `stat` = 기본 스탯의 before → after(탐침 기준 공격력 100 · 체력/실드 1000),
  `px` = 그 특전이 켠 내부 플래그·누산기. 곱연산(`p.dmg *= 1.15`)은 `from 100 → to 115` 로 나타난다.

## 값이 어디서 오는가 (규약)

값은 **엔진에서 직접** 읽는다 — `sim.js` 를 다른 게이트와 같은 방식으로 vm 컨텍스트에 올려
실제 객체·함수를 호출해 뽑는다. 소스 문자열에서 «값» 을 긁지 않는다. 예외 두 곳:

- **ⓐ `ui.json`** — `index.html` 은 브라우저 DOM 없이 올릴 수 없어, 상수 **이름**으로 찾아 그 식을 계산한다.
- **ⓑ `combat.json` 의 이동·사거리·투사체 속도·적 공격 주기·상한** — 엔진에 **이름이 없는 리터럴**
  (`runChapter` 안의 `132`·`74`·`105`·`440` 등)이라 엔진 **함수 객체의 소스**(`Function.toString()`)에서 뽑는다.
- **ⓒ** 둘 다 값이 바뀌면 재생성 결과가 바뀌므로 드리프트 게이트(`--check`)는 그대로 작동한다 —
  `verifyExportData` 의 음성 6종이 그것을 실측한다(정지 거리 74 → 75 로 흔들면 실제로 빨개진다).

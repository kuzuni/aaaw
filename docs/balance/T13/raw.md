## 1. 이론 — «왜 101+ 에서만 무너지는가» 는 한 줄 부등식으로 결정된다

영구강화 폐지 후 후반 전투력의 성장 축은 **슬롯 강화 하나뿐**이다(장비는 신화 풀셋 도달 후
`+N강`이 `1+0.12N` 의 **선형** 증가라 지수 곡선을 따라올 수 없다 — `GT.plusStep`, `sim.js:195`).

- 슬롯 레벨당 전투력 배수 = `slotG` = 2.68
- 챕터당 획득 슬롯 레벨 `dL/dc` = `ln(goldGrowth) / ln(slotCostG)`
- 따라서 **챕터당 플레이어 파워 성장 = `slotG^(ln goldGrowth / ln slotCostG)`**
- 챕터당 적 HP 성장 = `eHpG` = 1.185

| 항목 | 현행값(R07) | 값 |
|---|---|---|
| 슬롯 1렙이 벌어 주는 챕터 수 `ln slotG / ln eHpG` | — | **5.808 챕터** |
| 챕터당 획득 슬롯 레벨 `ln 1.22 / ln 4.2` | goldGrowth 1.22 · slotCostG 4.2 | **0.1386 렙** |
| 챕터당 파워 성장 `2.68^0.1386` | — | **1.1464** |
| 챕터당 적 HP 성장 | — | **1.185** |
| **적 대비 배수** | — | **0.9674 (매 챕터 3.4% 씩 뒤처진다)** |
| 100챕터 누적 열세 | — | **1/27.5 배** |

**즉 지속 조건은 `slotCostG ≤ goldGrowth^(ln slotG / ln eHpG)` = `1.22^5.808` = 3.174 인데,
현행 4.2 는 이 조건을 위반한다.** PLAN §7 이 «R07 확정값 4.2 는 이를 만족» 이라 적어 둔 것은
**계산 착오**다(4.2 > 3.174). T6 의 옛 규칙 `slotCostG < goldGrowth^6` = 3.297 과 R07 의 새 규칙은
사실상 같은 식이며, **두 규칙 모두 4.2 를 허용하지 않는다.**

### 왜 1~100 은 멀쩡한가
장비가 «일반→신화» 로 오르는 동안(대략 챕터 100 이전) 등급업이 `rarStep` = 155배씩 얹어 주기 때문에
슬롯의 3.4%/챕터 적자를 덮는다. **신화 풀셋에 도달하는 순간 그 보정이 사라지고 적자가 그대로 노출된다.**
실측에서 신화 풀셋 완성 시점이 챕터 100~110 이고, 열화 시작점이 정확히 거기다.

### 시도 횟수는 왜 «단조 악화» 하는가
시도 횟수 `A(c)` 는 골드 수입을 통해 자기보정한다. 정상상태 조건은
`d(ln A)/dc = ln eHpG · ln slotCostG / ln slotG − ln goldGrowth` = **0.0483/챕터**,
즉 **시도 횟수가 챕터당 4.9% 씩 늘어난다**(100챕터마다 ×123). 챕터 100 에서 2~3회면
챕터 200 근처에서 300~400회에 닿아 `EXP3_LIMIT` 에 막힌다 — 워커 C 가 챕터 186 에서 관측한 393회가 이것이다.

### 앵커가 요구하는 값
앵커 A(챕터 90·슬롯 15) → 앵커 B(챕터 300·슬롯 50) = **210챕터에 35렙 = 6.0챕터/렙**.
`slotG = eHpG^6 = 2.77`(실제 2.68)로 이미 이 제약에서 역산돼 있다. **경제도 같은 기울기를 내야 한다**:
`dL/dc = 1/6 = 0.1667` → `slotCostG = goldGrowth^6 = 3.297`. 현행 0.1386 은 이 값의 **83%** 다.

## 4. 부작용 점검 — 다른 실험은 영향받지 않는다

- **실험1·2**: 하니스가 `mkBuild(등급, 강화, 슬롯레벨)` 로 슬롯 «레벨» 을 직접 지정한다.
  `slotCostG` 는 비용 곡선이라 **하니스 빌드가 바뀌지 않는다.**
  T5 재보정 규칙(«그 챕터 도달 시점 관측 중앙값»)도 재보정이 필요 없다 — 실측:

## §4. 무료 새로고침(PLAN §2.4)이 엔진에 아예 없다 — 반영하면 밸런스가 크게 움직인다

PLAN §2.4 는 «레벨업 → 특전 3개 중 1개 선택, **무료 새로고침 1회**(🎲 보유 시 +1)» 이고
PLAN §3.0 은 «🎲 새로고침 시에는 **등급부터 다시 굴린다**» 라고 못박았다.
그런데 `perkChoice()` 에는 새로고침이 한 줄도 없다 — 뜬 등급을 그대로 쓴다.

등급통일 지시(§3.0) 때문에 이 차이가 특히 크다: 새로고침 1회는 사실상 **«일반이 뜨면 다시 굴린다»** 이고,
그러면 일반 등장이 30% → 9% 로 줄고 전설+신화가 40% → 52% 로 오른다.
스크래치 사본(`rollPerks` 만 패치, 레포 엔진 무수정)으로 챕터8 클리어율 N=15000 측정:

|---|---|
| 현행(새로고침 없음) | **68.0%** |
| 일반이 뜨면 1회 재굴림 | **76.2%** (+8.2%p) |
| 일반·희귀면 1회 재굴림 | **78.0%** (+10.0%p) |

**T1 은 지금 «실제 게임보다 8%p 약한 플레이어» 를 기준으로 튜닝하고 있고, T2 가 PLAN 대로 이식하면
게임은 시뮬보다 그만큼 쉬워진다.** T23(«PLAN 에 없는 값이 채점을 지배») 의 거울상 —
이번엔 **PLAN 에 있는 값이 엔진에 없다.** → **승인 대기 20번.**

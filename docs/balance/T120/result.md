## 2. 자(尺) 고정 — `perkMode:'base10'` (주인 확정 ①)

주인이 못박은 **«기준 플레이어»** = 기존 일반 10종을 §3.1 **옛 순서**대로 «되는 만큼» **자동 획득 ·
3택 없음 · 신규 22종·등급 없음**. T114 가 8/8 을 낸 바로 그 조건이다.

옛 순서(= `PERKS_BASE10` = 풀 앞머리 10개):
회복 → 공격력 → 회피율 → 화살 → 도끼 → 반격률 → 창 → 치확 → 치피 → 방어력
(`p_evadeHeal` · `p_atk` · `p_evade` · `p_arrowEv` · `p_axeHit` · `p_counter` · `p_spearCt` · `p_critR` · `p_critF` · `p_def`).

**⚑ 실제 게임 동작은 3택 그대로다 — 자만 고정한 것이다.** `runChapter` 의 `perkMode` 기본값은
`PERK_MODE_PLAY`(`'3pick'`)이고, 사다리를 재는 자리만 `PERK_MODE_LADDER`(`'base10'`)를 넘긴다.

| 자리 | 배선 |
|---|---|
| `sim.js` | `const PERK_MODE_PLAY='3pick', PERK_MODE_LADDER='base10'` · `const PERKS_BASE10=PERKS.slice(0,10)` |
| `runChapter(c,b,opts)` | `perkMode:opts.perkMode\|\|PERK_MODE_PLAY` (기본 = 게임과 같은 3택) |
| `grantNextPerk` | base10 이면 `PERKS_BASE10[G.taken.length]` 를 그대로 지급 — **3택 굴림을 안 거치므로 난수를 한 번도 안 쓴다**(T114 스트림과 같다) |
| 실험1 | `EXP1_PERKMODE = process.env.EXP1_PERKMODE \|\| PERK_MODE_LADDER` → `runChapter(c,b,{perkMode:EXP1_PERKMODE})` |
| 실험5(진단) | `runChapter(c,b,{perkMode:PERK_MODE_LADDER})` — 판정 자와 같은 자로 본다 |
| `tools/regress.js` | `delete env.EXP1_PERKMODE`(+`EXP1_N`·`EXP1_SPAN`) — 판수와 같은 이유로 **자도 상속시키지 않는다** |
| `verifyScoreCriteria` ⓓ | `S.runChapter(g.ch, builds[i], { perkMode: S.PERK_MODE_LADDER })` |

`EXP1_PERKMODE=3pick` 은 §3 의 참고표를 찍기 위한 **진단 전용 스위치**이고 판정 자가 아니다.

## 4. ⚑ 주인께 볼 것 1건 (판정 아님 · 루틴은 아무것도 안 고쳤다)

**참고표가 기준표와 크게 갈린다 — 그리고 방향이 앞뒤로 반대다.**
3택·32종 조건에서 실제 유저가 겪는 난이도는 **1~5칸(챕터 5~70)에서 과녁의 5~9배로 쉽고**(과녁 10% ↔ 실측 52~89%),
**7·8칸(챕터 380·420)에서는 과녁의 1/4로 어렵다**(10% ↔ 2.6~3.0%). 원인은 두 가지로 갈린다.

- **앞쪽이 쉬운 이유** — 3택은 «되는 만큼»(6~9개)을 32종 풀에서 고르므로 시뮬 정책상 **전설·희귀가 우선 뽑힌다**.
  «처치 시 번개/화살/도끼 100%» 같은 전설 소환이 초반 칸에 들어오면 웨이브가 통째로 지워진다
  (T119 가 등재한 소환 연쇄 **B = 9.0**, 승인 대기 50번이 바로 이 축이다).
- **뒤쪽이 어려운 이유** — 후반 칸은 «10종을 다 얻는 것» 이 전제인데, 3택은 32종 중 6~9개만 얻으므로
  **기준 10종의 공격력·치확·치피·방어력이 통째로 빠지는 런**이 흔하다. 기준 조건이 언제나 그 10종을 다 주는 것과 대비된다.

**루틴은 이 사실만 적고 아무것도 조정하지 않았다** — 주인 확정 ④ 의 상시 규칙(«플레이어 쪽이 바뀌어도
적 스탯을 임의로 재적합하지 않는다 · 재적합은 주인이 «맞춰라» 라고 한 경우에만»)을 그대로 따른다.
**«맞춰라» 가 오면** 그때도 자는 §2 의 기준 조건 하나이고, 3택 쪽을 과녁에 맞추려면 적 스탯이 아니라
특전 풀(전설 소환 계수·등급 확률)을 손대야 한다는 것이 이 표의 읽는 법이다 — 판단은 주인 몫이다.

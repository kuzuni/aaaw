# T53 원시 실측 — R01 재적합 곡선에서 F2P 계정이 챕터 300 에 도달하지 못한다

측정: 2026-09-02T11:0X~11:2XZ · sess-1050-27431 / 워커 D · 커밋 `f326596`(T1 재개 R01) 기준.
엔진 무수정 — 전부 환경변수(`SEED` · `GT_OVERRIDE`)만 걸어서 잰 값이다.

## 0. 이 결함이 게이트에 안 잡히는 이유

같은 커밋에서 상시 게이트 14종 exit 0 · T3 4스위트 127/127 · 실험5 사다리 7/7 이 **전부 초록**이다.
사다리는 «과녁 챕터 한 판» 의 클리어율만 재고(누적 진행을 안 본다), 실험3 은 게이트가 아니라 채점 실험이다.
즉 «한 챕터를 겨우 깰 수 있는가» 는 맞췄는데 «거기까지 걸어갈 수 있는가» 는 아무도 안 보고 있었다.

## 2. 계정은 성장 중인데 곡선이 더 빠르다 (SEED=202 정체 직전)

```
챕터 189: 시도  79회  슬롯 34/34/34/34/34/34  전투력 공2.12e+3·체4.17e+3
챕터 190: 시도   6회  슬롯 34/34/34/34/34/34  전투력 공2.12e+3·체4.17e+3
챕터 191: 시도 400회  슬롯 35/35/35/35/35/35  전투력 공2.22e+3·체4.36e+3   ** 400회 실패 **
```

슬롯도 오르고 전투력도 오르는데 400연패다 — 골드가 말라서 멈춘 것이 아니다.

## 3. 경제 노브로는 못 넘는다 (`GT_OVERRIDE` 탐침 6종 × 2시드)

| slotCostBase | slotCostG | SEED=202 정체 | SEED=303 정체 |
|---|---|---|---|
| 600 (현행) | **3.5 (현행)** | 191 | 202 |
| 600 | 3.2 | 251 | 251 |
| 600 | **3.0** | **258** | **274** |
| 600 | 2.6 | 253 | 252 |
| 300 | 3.2 | 269 | 257 |
| 300 | 2.6 | 208 | 220 |

- 슬롯을 싸게 하면 191·202 → 250~275 까지는 밀린다. **그러나 어느 값도 300 에 못 닿는다.**
- 더 싸게(2.6) 한다고 더 가지 않고, `base 300 + costG 2.6` 은 **오히려 208·220 으로 나빠진다**
  (싼 초반에 슬롯을 몰아 올리면 장비 뽑기에 갈 자원이 줄어 후반 장비 등급이 뒤처진다).
- 근인은 **차원이 다르다**: 슬롯 보상은 `1 + 0.01*L` 로 **선형**인데 적 성장은 챕터당 **1.54% 기하**다.
  선형은 기하를 못 이기므로, 어느 챕터 이후로는 골드를 아무리 부어도 따라잡히지 않는다.

## 4. 진짜 간극 — 사다리가 가정한 장비 vs 경제가 주는 장비

| | 장비 | 슬롯 |
|---|---|---|
| 사다리 260 칸이 전제하는 계정 | **신화 +9강 풀셋** | 0렙 |
| 실측 F2P 계정 (108일차 · 챕터 191) | **신화 +1 풀셋** | 35렙 |

이 차이를 메울 두 축은 **뽑기 확률·50회 천장**과 **다이아 2500/일** 인데 PLAN §7 이 «주인 확정 상수라 노브 아님»
으로 못 박아 뒀다. 즉 **T1 이 §7 노브만으로 닫을 수 있는 간극인지 자체가 불확실**하다.

## 6. T1 인계 — 시도해 볼 순서 (전부 위임 제안, 확정 아님)

- **ⓐ 260→300 을 별도 구간으로 분리한다.** 지금은 `eHpSeg` 마지막 항이 `[120, 1.0154]` 라 260 이후에도
  1.54% 가 그대로 연장된다(PLAN §11.7 괄호 규정). 그런데 같은 §11.7 산문은 260→300 을
  «슬롯 몫 — 필요 ×1.25(슬롯 균등 10~12렙)» 로 설계해 뒀고, 현행 률을 연장하면 ×**1.84** 가 된다.
  `[260, 1.0056]`(= 1.25^(1/40)) 를 덧붙이면 산문 설계와 맞고 **사다리 7점은 전부 260 이하라 안 흔들린다.**
  워커 D 예행 측정(자체 곡선, 200판): 신화+9강 슬롯 15렙 → 300장 5.5% · 슬롯 20렙 → 10.0%
  — 즉 «최종 벽이되 뚫린다» 가 성립한다.
- **ⓑ 벽 배수 8개를 되살린다** (실험3 의 벽 3칸 0점과 같은 뿌리다). 사다리 과녁 챕터(5·15·30·50·70·120·260)와
  벽 챕터(10·15·90·300)가 **15 에서 겹치므로** 그 칸만 재측정하며 넣을 것.
- **ⓒ ⓐ·ⓑ 로도 안 닫히면 주인 승인 대기로 등재한다.** «신화 +9강 풀셋을 F2P 가 며칠에 갖는가» 는
  뽑기 확률·천장·다이아 수급이 정하는 값이고 셋 다 주인 확정 상수다.

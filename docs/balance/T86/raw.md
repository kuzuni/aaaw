P3 다음 회차 R04 는 **주인 승인 40·41번 답 대기**라 착수 불가였다.
R03 인계문이 «답 없이 깨면 엔진을 건드리지 말고 게이트 재실행 검증만 하라» 고 지정해 둔 상태.

게이트 재실행(20종 exit 0 · T3 197/197)에서 `verifyNumClean` 만 «✎ 안내» 를 찍고 있었다:

```

Ⓓ 확률 5의 배수      — 등재  5건 중  4건 해소
```

**문제는 두 번째 묶음이다.** 이 id 들은 지금 깨끗하지만 **면죄부는 그대로 들고 있었다** —
P3 회차가 매 라운드 특전 수치를 만지는 와중에 이 id 에 소수점이나 5% 단위 위반을 **다시 써 넣어도

하필 그 목록이 **P3 가 직전 두 회차에서 실제로 만진 희귀 특전들**이라 위험이 이론이 아니었다.

### ⚑ 정리하고 나니 드러난 사실 — 새 132종은 이미 규칙을 지키고 있다

잔여 39건의 성격이 깔끔하게 갈렸다:

- **특전 잔여 = 6종뿐이고 전부 «주인 확정 예외»** — `c_evadePerm`(🍃 처치 시 회피 +1%) ·
  `c_collAtk`·`c_collEvade`·`c_collCounter`·`c_collDef`(🃏 수집가 4종 «보유 특전 1개당 +2%») ·

  주인 동결이라 워커가 못 고친다.
- **나머지 33건은 전부 장비 옵션** (`장비 …옵N`) — 특전이 아니다.

달리 말해 **P1 이 정본대로 이식한 새 132종은, 주인이 예외로 남긴 6종을 빼면 네 규칙을 전부 지키고 있다.**

**Ⓔ 축은 잔여 0건이 되어 이제 전면 강제**다 — 지속시간에 0.5초 배수가 아닌 값이 들어오면 무조건 빨개진다.

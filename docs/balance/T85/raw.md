## 1. 난이도 영점 — 적 기저 ×1.4925

**주인 지시**: «① 일반 특전만 뜨는 기준 플레이어(희귀 풀셋)가 해당 챕터에서 **10%** 가 되도록 **적 밸런스(난이도 노브)로만** 영점 조정 (적 ×10 시작점 조항 유지)».

### 1-1. 노브 선택 — 왜 «기저 하나» 인가

먼저 «구간별 성장률을 구간마다 다시 적합» 하는 안을 실측했다(스크래치패드 `fit.js` — 구간마다 스칼라 `a` 로 `1+a*(현행률−1)`, 사다리 7과녁을 아래에서부터 순차 이분탐색). 결과는 **사다리 7/7 합격**이었다:

```
eBaseHp:43.123, eBaseDmg:8.017,
eHpSeg :[[0,1.04141],[15,1.16003],[20,1.01024],[30,1.03927],[50,1.07387],[70,1.01503],[120,1.01876],[260,1.0056]]
eDmgSeg:[[0,1.03758],[15,1.16003],[20,1.01024],[30,1.02425],[50,1.0352 ],[70,1.02031],[120,1.01742],[260,1.0056]]
→ 사다리 8.0 / 7.5 / 5.5 / 7.5 / 6.5 / 7.5 / 4.5%  = 7/7 ✓
```

**그런데 이 지점에서 실험1 «일반 고정» 이 0.0~0.3%** 였다(3시드). 즉 사다리 7/7 과 «일반 10%» 는 같은 난이도에서 동시에 성립하지 않는다(§4 에 별건으로 등재). 주인 절차가 **①단계 = 일반 영점**이고 사다리는 ④단계 «재검증» 이므로, 이 회차는 **일반 영점을 채택**하고 위 7/7 적합값은 근거로만 남긴다.

채택 노브는 **기저 배수 하나**다 — 구간별 성장률 표(§11.7)·벽 배수를 한 칸도 안 건드리므로 **챕터 간 상대 난이도(사다리 모양·§6 «벽 예산» 항등식)가 통째로 보존**된다. 노브 교차 금지 조항과도 맞다.

## 4. ⚠ 주인 판단 대기

### 4-1. «실험1 등급 과녁» 과 «실험5 사다리» 는 동시 만족 불가

한 난이도에서 두 과녁이 요구하는 클리어율이 서로 어긋난다. 챕터 30 · 희귀 풀셋(두 실험이 **같은 빌드·같은 챕터**를 쓴다)에서 실측한 값:

| 측정 조건 | 채택 난이도(40.0/7.44) | §1-1 사다리 7/7 난이도(43.1/8.02) |
|---|---|---|
| 특전 없음 (`noPerk`) | 0.0% | 0.0% |
| **일반 특전만** (실험1 과녁 **10%**) | **8.4%** | 0.0~0.3% |
| 희귀 특전만 (과녁 20%) | 20.7% | 5.0% |
| 전설 특전만 (과녁 80%) | 70.3% | 30.3% |
| **혼합 = 실험5 희귀 칸** (과녁 **2~10%**) | **24.0%** | 5.3% |

- «혼합» 은 정의상 «일반만» 보다 항상 높다(45/35/20 풀에 희귀·전설이 섞이니까). 그래서 **일반 = 10% 인 난이도에서 혼합은 반드시 10% 를 넘고**, 실험5 희귀 칸(2~10%)은 구조적으로 못 맞춘다. ②단계가 희귀·전설을 **올리는** 방향이라 간극은 더 벌어진다.
- 반대로 사다리를 PLAN 문면대로 **«특전 미획득»** 으로 재면 같은 지점이 **0.0%** 라 이번엔 하한 2% 아래다. 즉 **특전이 클리어율의 지배 요인이라 «특전 없음 0%» ↔ «특전 있음 24%» 사이에 2~10% 밴드가 없다.**
- **선택지(주인 몫)**: ⓐ 실험5 사다리를 «**일반 특전만** 뜨는 런» 으로 재정의한다(그러면 8.4% 로 이번 회차에 이미 합격이고, 실험1 ①단계와 자를 공유한다) · ⓑ 사다리 합격 구간 2~10% 를 새 체제에 맞게 넓힌다 · ⓒ 실험1 등급 과녁을 우선하고 사다리는 «참고 지표» 로 강등한다.
- 이 회차는 아무 것도 고르지 않고 **현행 구현(특전 포함)** 그대로 재서 3/7 로 보고했다. 다만 PLAN 문면(«특전 미획득»)과 코드가 달랐던 것은 **자(尺) 파손**이라 `runChapter` 에 `noPerk` 옵션을 신설해 두 자를 다 쓸 수 있게만 해 뒀다(기본 동작 불변 — 실험5 는 여전히 종전대로 돈다).

### 4-2. «일반 44종 동결» 과 «실험2 등급 내 폭 <25%p» 도 동시 만족 불가

§3 실험2 에서 **일반 등급 폭이 43.2%p** 인데(`c_killHeal2` 95.3 ↔ `c_thornsS` 52.1), 주인 확정 «일반 44종은 내용·수치 전부 동결» + 절차 ③ «조정은 희귀·전설만» 이라 **워커가 이 값을 줄일 수단이 없다.** 새로 만든 `verifyCommonFreeze` 게이트가 일반 특전 수정을 정확히 그 이유로 막는다.

즉 채점표 v3 의 실험2 1점은 **최대 2/3점**으로 상한이 걸린다. 총점 10 중 1/3 점을 미리 잃고 시작하므로 «두 비평가 각 ≥8» 게이트가 그만큼 좁아진다.

**선택지(주인 몫)**: ⓐ 일반 등급은 폭 판정에서 제외하고 실험2 1점을 희귀·전설 각 1/2점으로 재배분 · ⓑ 일반 동결을 «표시 텍스트·효과 구조는 동결, 수치는 등급 내 영합 재분배만 허용» 으로 완화 · ⓒ 그대로 두고 실험2 만점은 포기(총점 상한 9.67).

⚠ 어느 쪽이든 **일반 특전을 워커가 고칠 수 있게 되기 전까지는 워커가 손댈 수 없다** — 이 회차는 측정·보고만 했다.

## 2. 신설 게이트

### `verifyT2` ㊳ — 주기형 회복 금지 (2항목)

낱말이 아니라 **구조**로 본다. 두 엔진에서 주기 패턴 `X -= dt; if (X <= 0) { X = <주기>; …몸통… }` 을 전부
떠서 **몸통에 회복·실드 충전(`heal(`·`.hp +=`·`.sh = Math.min`·`.sh +=`·`gainWard(`)이 들어 있으면 빨개진다.**

«3초마다 체력 `<b>`3%`</b>` 회복» 처럼 태그 하나로 검사를 빠져나가는 구멍을 자가 시험에서 실제로 찾아 막았다.

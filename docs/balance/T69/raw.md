# T69 — 반격 연쇄 특전(`l_counterChain`)이 sim.js 에서 죽어 있었다 (원시 측정)

> 워커 B · sess-1520-24921 · 2026-09-02T15:3X~16:0XZ

## 1. 증상과 원인

```js
/* 종전 (sim.js) */                                   /* index.html (정상) */
else if(px.counterChain&&depth<2&&Math.random()<1.0)   else if(px.counterChain&&!depth)
  doCounter(G,src,1);                                    doCounter(src,1);
```

`doCounter` 의 바깥 호출부는 **두 곳 다 depth 를 안 넘긴다**:

| 파일 | 호출부 | 인자 |
|---|---|---|
| sim.js:891 | `evadeCounter`(회피 시 반격) | `doCounter(G,src)` |
| sim.js:937 | 피격 반격(`counter`·`hitCounter`) | `doCounter(G,src)` |
| index.html:2566 · 2649 | 같은 두 자리 | `doCounter(src)` |

그래서 sim 의 `depth` 는 항상 `undefined` 이고, **`undefined < 2` 는 NaN 비교라 언제나 false** 다.
즉 전설 특전 «🔂 반격 시 반드시 한 번 더 반격(연쇄 2회 제한)» 이 **시뮬에서 단 한 번도 발동하지 않았다.**
게임(`index.html`)은 `!depth` 라 정상 동작했으므로 **sim↔게임 괴리**이기도 하다 —
T1 의 모든 회차가 «게임에는 있는데 시뮬에는 없는» 특전을 하나 안고 측정한 셈이다.

덧붙은 `Math.random()<1.0` 은 항상 참이라 확률처럼 읽히는 죽은 조건이었다(스펙은 «반드시»). 함께 제거.

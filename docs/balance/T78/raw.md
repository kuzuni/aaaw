# T78 — 소환 연쇄 임계 규칙 (원시 측정)

> 주인 확정 (2026-09-03, ROUTINE 맨 위): «소환 1발의 적중이 낳는 신규 소환 기대값 ≤ 0.8 을
> 어떤 특전 조합에서도 유지». 기대값 = Σ 보유 소환 특전의 발동확률 × 발수.
> 워커 D · sess-1852-14986 · 2026-09-02T18:5XZ~

## 1. 개정 전 진단 — 최악 조합은 초임계였다

`node tools/verifySummonChain.js` (개정 전 HEAD=05b5bec 기준):

```
    도끼    15% × 14발 = 2.100  (m_axe3 반영)
    화살    15% × 24발 = 3.600  (m_arrow4 반영)
    검기    20% × 1발  = 0.200
    창     7.5% × 1발  = 0.075
    번개    10% × 20발 = 2.000  (m_bolt3 반영)
    무기고   16% × 12.0발(5종 평균) = 1.920
    ── 소계 9.895 × 폭풍의 힘 1.22 = 12.072
    ＋ 빗맞음 창 10%(적 회피) × 1.22 × 30% = 0.037
    ＝ 기대값 B = 12.108      ← 임계 0.8 의 15.1 배
```

엔진 실측(20만 회 몬테카를로)도 같은 값이 나왔다: **B = 12.094**(SE 0.032).
B ≥ 1 이면 한 타격의 총 소환 수가 등비급수로 발산하고 `PROC_TICK_CAP=200` 이 끊을 때까지 부푼다 —
주인이 지목한 «신화 뜨면 게임 끝» 의 정체가 이것이다. 주인 예시 «도끼 14개 × 15% = 2.1» 은
**한 항만으로도 이미 초임계**였고, 실제로는 그 항이 여섯 개 중 하나였다.

> ⚠ 발견 1건 — **신화 발수 특전이 하나도 없어도 초임계다.** 발수 특전을 전부 뺀 «기본 소환 5종 + 무기고»
> 만으로도 B = 1.44 라 1 을 넘는다. 즉 «신화 하향» 만으로는 주인 조건을 못 맞추고
> 기본 소환 특전의 발동 확률까지 내려야 한다 — 아래 개정이 그 이유다.

## 2. 개정 — 무엇을 얼마로

주인 규칙(확률 10% 단위, 예외적으로 5% 허용 · 소수점 금지)을 지켜 **「공격 시」 소환 6종의 발동 확률을
전부 5% 로 통일**하고 발수를 내렸다. 소환 데미지 계수(도끼 50% · 화살 65% · 검기 70% · 번개 75% · 창 100%)와
창 관통 8마리, 폭풍의 힘 1.22배는 **손대지 않았다**(주인 확정 상수 · 다른 지시의 관할).

| 축 | 개정 전 | 개정 후 |
|---|---|---|
| 🪓 도끼 (`r_axe`) | 공격 시 15% · 1개 | **5% · 1개** |
| 🏹 화살 (`r_arrow`) | 공격 시 15% · 2발 | **5% · 2발** |
| 🌊 검기 (`r_wave`) | 공격 시 20% · 1개 | **5% · 1개** |
| 🔱 창 (`l_spear`) | 공격 시 7.5% · 1개 | **5% · 1개** |
| ⚡ 번개 (`l_bolt`) | 공격 시 10% · 2회 | **5% · 1회** |
| 🎇 무기고 (`m_arsenal`) | 공격 시 16% | **5%** |
| 🪓 도끼 폭풍 (`m_axe3`) | 14개 | **3개** |
| 🏹 화살 폭풍 (`m_arrow4`) | 24발 | **3발** |
| ⚡ 번개 지배자 (`m_bolt3`) | 20회 | **2회** |

같은 수치가 **장비 옵션 표(§11.6)에도 그대로** 들어 있어(도끼 계열 2·4·5단계 등) 함께 고쳤다 —
장비 옵션과 특전은 같은 `px` 키를 올리므로 확률은 `procOnAttack` 한 자리에서 나온다.
겸사겸사 주인이 금지한 «%p» 표기 3건(«도끼 발사 확률 +15%p» 등)을 «+5%» 로 정리했다.

개정 후 최악 조합:

```
    도끼     5% × 3발 = 0.150      화살     5% × 3발 = 0.150
    검기     5% × 1발 = 0.050      창      5% × 1발 = 0.050
    번개     5% × 2발 = 0.100      무기고    5% × 2.0발 = 0.100
    ── 소계 0.600 × 1.22 = 0.732  ＋ 빗맞음 창 0.037  ＝ B = 0.769 ≤ 0.8 ✓
```

엔진 실측 **0.769**(SE 0.0029) — 분석값과 소수 셋째 자리까지 일치. 총 소환 배수 1/(1−B) = **4.32배**로 수렴한다.
발수 특전이 없는 «기본 소환만» 조합은 B = 0.476.

## 6. 남은 것 — 주인 판단이 필요한 2건 (PROGRESS 승인 등재)

1. **관통을 «적중» 으로 세면 아직 초임계다.** 주인 문언의 기대값은 «발동확률 × 발수» 라 이번 게이트는
   발사 기준으로 쟀다. 그런데 검기(검기의 왕 관통 20)·창(관통 8)은 **1발이 여러 번 적중하고 적중마다
   트리거를 다시 굴린다.** 적중 수로 세면 개정 후에도 **B = 2.672**(개정 전 18.400)다 — 그 줄에 적이
   그만큼 서 있을 때만이지만, 다수 웨이브에서는 성립한다. 판정 축을 «적중 기준» 으로 옮기려면
   검기의 왕 관통 20 을 내려야 하고 그건 주인이 확정한 특전 내용이라 워커가 손대지 않았다.
2. **같은 소환 특전을 여러 번 얻으면 임계가 깨진다.** 소환 특전은 고유(`u:1`)가 아니라 중복 획득되고
   장비 옵션도 같은 `px` 키를 올린다(도끼 계열 무기 하나가 `px.axe` 를 2 올린다). 주인 문언이
   «모든 소환+발수 특전 동시 보유» 라 게이트는 «각 1개» 로 잰다. 진짜로 못 넘게 하려면
   소환 특전을 고유로 만들거나 `px` 키에 상한을 두어야 하는데 둘 다 구조 변경이라 승인 대기로 둔다.

## 1. 먼저 기각한 가설 2개 (음성 결과 — 다음 워커는 다시 돌리지 말 것)

- **사장된 px 키(엔진이 쓰지 않는 효과)가 있는가** → **없다.** `basePx()` 83개 키 전수 정적 대조 결과
  읽기 0회인 키는 0개. 플레이어 스칼라 30개도 전부 접근자(`effDmg`/`effAspd`/…)에서 읽힌다.

## 2. 발견 — 특전과 장비옵션이 같은 px 키를 쓴다 (기존 게이트 미검사 축)

§11.6 옵션표는 설계 제약상 «기존 엔진 동사만 재사용» 해서 만들었다(T6). 그래서 **102종 특전이 쓰는 px 키를
장비 옵션이 그대로 다시 쓴다.** 공유되는 키가 **70개**다. 그중 실제로 효과가 버려지는 것이 아래 21쌍.

T19 게이트는 이 축을 구조적으로 볼 수 없다 — 파싱 대상이 GOPT 126칸뿐이고 `mkPerks()` 를 읽지 않는다.
게다가 T19 게이트가 `counterWave` 를 ALLOW 하며 적은 사유 **«대검 계열 단독이라 계열 간 누적도 없다»** 는
장비끼리만 보면 맞지만, 전설 특전 `l_counterWave` 가 같은 키를 올리므로 **특전 축에서는 틀렸다.**

### 실측 대조 — `m_wave4` 의 효과가 정말 0인가

`EXP2_FULL=1 node sim.js 2` (챕터8 · 신화0강 6부위 · 1200판):

```
전체 클리어율: 68.8%
[신화] … m_guard 71%(109) · m_wave4 68%(116) · m_autoBolt 68%(111) · …
```

`m_wave4` 채택 시 승률 **68%** = 전체 클리어율 **68.8%** 와 구별 불가. 정적 분석(효과 0)이 실측으로 확인된다.
신화 22종 중 15위 — 바닥은 아니라서 **지금은 실험2 스프레드(19.1%p, OK)를 깨고 있지 않다.** 그래서 이 건은
현재 채점 점수를 직접 깎지는 않는다. 문제는 앵커 B 쪽이다.

### 앵커 B 의 손실 크기

`rollRarity` 는 신화 15% · 전설 25% · 희귀 30% · 일반 30% 다. 앵커 B 에서 전설 28종 중 5종, 신화 22종 중 2종이
죽어 있으므로 **레벨업 1회당 «완전히 버려지는 선택» 확률 = 0.25 × 5/28 + 0.15 × 2/22 ≈ 5.8%**.
그중 `l_counterWave` 는 단발이 아니라 **매번 다시 뽑힐 수 있다.**

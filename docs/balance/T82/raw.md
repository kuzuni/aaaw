## 7. 게이트가 특전 재작성을 막지 않게 (2026-09-03 «전면 정지» 대응)

주인이 대화형 세션에서 특전 목록을 통째로 재작성 중이라 **id 가 바뀔 수 있다.** ⑧ 이 id 로만 보면 재작성본에서 애먼 불합격이 난다. 그래서 «id 가 없다» 는 곧장 불합격이 아니라 **효과가 사라졌나** 로 판정하게 했다:

- 네 id 가 두 엔진에서 모두 사라지면 → index.html 의 **일반 등급 특전 tx 를 훑어** «처치 시 체력 N% 회복» 을 찾는다.
- 있으면 **N = 5 인지**만 본다(주인 확정 상수). 없으면 «주인 확정 상수가 목록에서 사라졌다» 로 불합격.
- 음성 3종 확인: id 를 바꾸고 3% 로 → exit 1 · 일반 킬힐을 통째로 삭제 → exit 1 · **id 만 바꾸고 5% 유지 → 통과**(«특전 id 가 바뀌었다 — c_killRecov 가 5% 를 지키고 있다»).

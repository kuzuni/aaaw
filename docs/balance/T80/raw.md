# T80 — 실험2 채점 판수 1,200 → 12,000 (주인 지시 ① 이행)

> 세션 `sess-1906-1575` / 워커 A · 2026-09-02T19:0X~19:2XZ
> 주인 지시(ROUTINE 2026-09-03 «⚑⚑⚑ 주인 최종 결정»): **«T1 즉시 재개, 회차 1순위 = 실험2 «등급 내 밸런스» — ①측정은 12,000판 이상(노이즈 규명 반영)»**

## 1. 무엇을 왜 고쳤나

`sim.js` 의 실험2 채점 기본 판수가 **1,200판**이었다. 이 판수에서는 «등급 내 폭 <25%p» 라는 채점 항목이
**밸런스가 어떻든 측정 자체가 불가능**하다 — R05 두 비평가가 독립적으로 같은 결론을 냈다.

- **비평가 B 몬테카를로**(관측 표본수 그대로 · «등급 내 전 특전의 참승률이 완전히 같다» 는 귀무모형 3,000회):
  순수 잡음만의 기대 폭이 일반 20.3 · 희귀 20.8 · 전설 18.7 · **신화 26.5%p**.
  → **완벽하게 균형 잡힌 특전 집합이어도 신화 칸은 잡음만으로 합격선 25%p 를 넘긴다.**
- **비평가 A 판수 사다리**(같은 엔진·같은 하니스, 판수만 상향): 신화 칸 45.0 → 38.9 → **35.7%p**.

판수 상향은 **하니스(장비·챕터)를 옮기는 것이 아니라 같은 자로 더 오래 재는 것**이라 지표 조작이 아니고,
PLAN §7 이 이미 «진단 전용 무료 노브(`EXP2_N`)» 로 열어 둔 축이다. 이번에 그 노브의 **채점 기본값**을 올렸다.

## 2. 고친 것 (3파일)

| 파일 | 내용 |
|---|---|
| `sim.js` | `exp2_perkWinrate()` 의 기본 판수를 **이름 붙은 상수 `EXP2_SCORE_N=12000`** 으로 신설하고 `EXP2_N` 미지정 시 그 값을 쓰게 했다 (종전 리터럴 `'1200'`). `EXP2_N` 은 그대로 «더 늘려 점근값을 볼 때» 용 오버라이드 |
| `PLAN.md` §7 | «챕터30에서 ~~1200판~~ → **12000판**» + 판수 근거(몬테카를로·판수 사다리)를 문면에 박았다 |
| `tools/verifyScoreCriteria.js` | 판수 대조를 **상수 선언 + 사용처 2자리**로 바꾸고, **주인 확정 하한 «≥12,000» 단언**을 신설 |

**게이트를 «값 하나» 가 아니라 «두 자리 + 하한» 으로 짠 이유**: 상수 값만 보면 «상수는 12000 인데
기본값 자리엔 다른 리터럴» 인 우회를 놓치고, PLAN↔엔진 대조만 보면 **둘이 사이좋게 같이 내려가는 것**을 못 잡는다.
음성 테스트 5종이 정확히 그 다섯 가지 되돌림을 잡는다(§5).

## 3. 실측 — 판수만 바꾼 짝지음 (시드 11·12·13 고정, T74 규약)

엔진은 한 줄도 안 건드렸다. 같은 시드 · 같은 하니스(챕터 30 · 희귀 풀셋 · 슬롯 5렙) · 판수만 다르다.

### 등급 내 폭 (%p · 합격 = 25 미만)

| 등급 | 1,200판 s11 / s12 / s13 | 12,000판 s11 / s12 / s13 | 시드 간 폭 (1,200 → 12,000) |
|---|---|---|---|
| 일반 | 34.5 / 35.5 / 37.9 | **25.4 / 26.5 / 27.7** | 3.4 → **2.3** |
| 희귀 | 41.0 / 32.7 / 36.3 | **27.1 / 26.4 / 27.9** | 8.3 → **1.5** |
| 전설 | 25.1 / 27.7 / 26.1 | **21.4 / 20.0 / 21.9 ✅** | 2.6 → **1.9** |
| 신화 | 48.3 / 48.2 / 35.4 | **31.7 / 29.7 / 32.5** | 12.9 → **2.8** |
| **합격 등급 수** | **0/4 · 0/4 · 0/4** | **1/4 · 1/4 · 1/4** | |

전체 클리어율은 판수와 무관하게 같다 — 70.8/70.3/70.8(1,200) vs **70.8/70.4/69.9**(12,000).
**즉 이 상향은 «게임을 쉽게 만들어 점수를 딴 것» 이 아니라 «자의 눈금을 촘촘하게 한 것» 이다.**

- 잡음이 빠진 크기: 일반 −9.9 · 희귀 −8.9 · 전설 −5.1 · **신화 −13.0%p**(3시드 평균).
  등급별 크기 순서가 R05 비평가 B 의 귀무모형 예측(신화가 가장 크다 — 신화만 표본이 얇다)과 일치한다.
- **전설은 잡음만 빼도 곧바로 합격**한다(3시드 전부 20.0~21.9). 1,200판에서 «전설 25.1%p 초과» 였던 것은
  실제 불균형이 아니라 측정 잡음이었다.
- 남은 셋은 실제로 선 밖이다 — 신화 **약 31%p** 가 가장 멀고, 일반·희귀가 26~27%p 로 선에 붙어 있다.
  **T1 1순위(신화부터 영합 재분배)가 겨눠야 할 실제 크기는 «48%p» 가 아니라 «31%p», 줄여야 할 양은 6%p 남짓이다.**

### ⚑ T1 인계 — 12,000판으로도 «최하 1종» 지목은 못 믿는다

**상단 지목은 12,000판에서 안정되지만 하단은 여전히 흔들린다.** 원인은 표본이 아니라 분포다 —
하위 무리가 **61~63% 에 12종 넘게 촘촘히 붙어 있어**(s11 하위 12: 63/63/63/63/63/63/63/62/62/62/62/61%)
누가 «최하» 로 찍히느냐가 0.5%p 차이로 갈린다.
→ **T1 은 «최하 1종을 집어 올리는» 방식으로는 폭을 못 줄인다. 상단(m_stunKill·r_evadeShield 급)을 내리고
하위 «무리» 를 통째로 올리는 영합 재분배가 맞다** (주인 지시 ②의 «강한 것↓ 약한 것↑» 과 같은 방향).

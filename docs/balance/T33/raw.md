## 2. 게이트 사양 — `tools/verifyLegacyHtml.js`

대상: `index.html` 의 모든 `<script>` 를 추출한 소스 + `sim.js`(같은 잣대, 교차 확인용).

1. **웨이브 전멸 블록**(`enemies.every(...)` 의 if 본문)에 `.sh=`/`.hp=` 대입·`healPlayer(` 금지.
   블록 자체가 없으면 — sim.js 처럼 그런 분기가 아예 없는 경우 — 통과(충전할 자리가 없다).
   `index.html` 은 웨이브 진행에 이 블록을 쓰므로 **없으면 «파싱 실패» 로 불합격**(코드 모양이
   바뀌어 게이트가 눈을 감는 것을 막는다 — T27 게이트와 같은 규약).
2. **레벨업 경로** `gainExp` → `openPerkChoice` → `takePerk` → `afterPerk` 본문에
   회복 호출·풀충전·최대치 보정(`maxHp*=`, `maxSh+=` …) 금지. 특전 효과인 `px.perkHp` 줄만 예외.
3. **풀충전**(`X.sh = X.maxSh` / `X.hp = X.maxHp`, 뒤에 연산자가 붙는 비율 회복은 제외)은
   **PERKS 배열(특전 정의) 안에서만** 허용. 그 밖의 위치는 전부 불합격.
   `sim.js` 는 특전이 `add(...)` 형태라 PERKS 배열이 없으므로 빌드 셋업(`mkPlayer`)만 제외하고
   풀충전 0 을 요구한다.

**범위 제한(의도적)**: T2 미완 항목(흡혈 특전 3종 제거·버프 아이콘·특전 미리보기 등)은 검사하지
않는다. 지금 빨개져도 고칠 수 있는 워커가 없어(T2 는 T1 대기) 게이트가 상시 적색이 되면 무의미하다.

## 6. 남은 어긋남 (마감했지만 기록 — 주인이 더 붙이길 원하면 여기서 시작한다)

1. **적 스프라이트 크기** — 높이 ≈6.4%(ref ≈9%). 발밑은 맞췄으므로 남은 것은 «캐릭터를 키우는 것» 이고,
   그러면 «적 행 윗변 31.0» 이 따라온다. 다만 이건 **그림체 쪽에 가깝고**(주인 보강: 껍데기는 점수 밖)
   `drawCharOn` 의 스케일이 전투 연출 전반(피격·소환·투사체 자리)과 물려 있어 한 회차를 통째로 써야 한다.
2. **적과의 가로 간격** — 게임은 `e.aggro = d<290`(캔버스 540 단위 = 화면 53.7%)에서 멈춘다. ref 는 16.5%p 다.
   이 거리는 **전투 교전 규칙**이라 T116 의 «화면만 손댄다» 범위 밖이다(§1) — 손대지 않았다.
3. **상점 뽑기(상점 ②)** — 승인 대기 49번(아래).
4. **특전 획득창 상단 스탯 줄 8칸** — 승인 대기 48번(아래). 45번(스탯 7칸)과 같은 벽이다.
5. **인포 팝업 «닫기 안내»** — 게임은 버튼(y88.3 h5.8), ref 는 글자 안내(y91.5 h2.0). 버튼을 글자로 바꾸면
   맞지만 «누를 것이 안 보인다» 는 실사용 손해가 생긴다(U02 가 gearpop 에서 같은 종류의 결함을 잡았다).

6. **`--fh` 는 프레임 높이가 아니다** — U02 가 적어 둔 것이 그대로 유효하다(`min(100dvh, 100vw*19/9)` · 390×844 에서
   2.45% 작다). **390×844 에서는 실측으로 맞춰 놨으므로 채점에 영향이 없고**, 고치면 세로 값 전부를 ÷1.0251 로

### ⚠ 이번 회차에 실제로 밟은 함정 3개 (U03 이 같은 데서 안 넘어지게)

1. **CSS 재정의를 기본 규칙 «앞» 에 두면 게이트가 오독한다.** `verifyT2` 는 `.perk-card .ic{…}`·`.ov-foot{…}` 를
   정규식의 **첫 일치**로 읽는데, `#overlay.ov-full .perk-card .ic{…}` 가 위에 있으면 그것을 기본 규칙으로 착각해
   «메달리온이 아니다»·«오른쪽 정렬이 아니다» 로 빨개진다(실제로 4항목이 빨개졌다). **자식 재정의는 항상 뒤에.**
2. **`ov.className=…` 로 클래스를 갈면 ㊴③ 이 깨진다** — 게이트가 `ov.classList.add('on')` 리터럴을 센다.
   `className=''` → `classList.add(cls)` → `classList.add('on')` 순으로 쓰면 뜻도 같고 게이트도 초록이다.
3. **음수 margin 으로 두 줄을 같은 줄에 올리면 위 줄의 클릭을 덮는다.** `.ov-foot`(폭 100%)가 «계속 전진» 을
   가려 T3 battle 이 «버튼이 안 눌린다» 로 잡았다. 줄에 `pointer-events:none` · 자식에 `auto` 로 풀었다.

   레퍼런스에서 이것은 **상점의 다른 탭**인데 게임 상점은 한 화면이다. 지금은 상점(1) 구조에 맞췄으므로
   이 3행은 계속 X 다 — 상점을 두 탭으로 나누는 것은 새 기능이라 §1 금지축이다(형태만 재현할 여지는 있다).
5. **인게임 스탯 8칸** · **상점 상품 9종** — §7 승인 대기 2건(U01 등재분) 그대로.
6. 메타줄 h 2.0(ref 3.0) · 뽑기 버튼줄 y82.2(ref 상점(2) 33) 같은 잔여 1~2행.

## 7. ⚑ 주인 승인 대기 (레이아웃만으로는 못 넘는 것 — T116 ④ⓐ)

- (U01 등재) **인게임 스탯 그리드가 4행×2열 8칸이 안 된다** — 주인 지시(«흡혈 특전 전면 배제»)로 7칸이고
  게이트 ⑰ 이 그 7을 단언한다. 8칸을 채우려면 주인이 8번째 스탯을 정해 주셔야 한다.
- (U01 등재) **상점 상품이 1종뿐** — 레퍼런스는 젬 6 + 골드 3 = 9칸. U02 가 3열 2행 **6칸의 «형태»** 는
  잠금 카드로 채웠으나(살 수 있는 상품은 여전히 1종 · 게이트가 감시), 실제 상품을 늘리는 것은 새 콘텐츠다.
- **(U02 신규) 대장간 재료 슬롯이 «1칸» 이 될 수 없다** — 레퍼런스는 결과 슬롯 아래 재료가 **1칸(w17)** 인데
  게임의 합성은 **«같은 부위·종류·등급 3개»** 가 규칙이라(PLAN · `verifyGearEcon`·T3 gear 가 3칸을 단언)
  재료 줄이 최소 3칸이다. 칸을 줄여도 줄 폭이 25% 아래로 안 내려간다. 레이아웃만으로는 못 맞추는 벽이라
  ⓐ «3칸 그대로 두고 이 행은 영구 감점» ⓑ «합성 재료 수를 바꾼다(밸런스·규칙 변경)» 중 주인 선택이 필요하다.
  워커는 손대지 않았다(ⓐ 로 두고 나머지 9행을 맞췄다).

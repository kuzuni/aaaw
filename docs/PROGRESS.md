### R02 튜닝 근거 (구조 분석)

- 초기 스펙은 **수학적으로 20챕터 완주가 불가능**했다. 플레이어 전투력은 강화 레벨 L 에 대해 약 L²,
  L 은 골드 총량의 로그(비용 40*1.32^L), 골드 총량은 챕터에 선형 → 전투력은 (log c)² 로 자라는데
  적은 1.35^c 로 자란다. 그래서 400판을 4000판으로 늘려도 챕터10 이 안 뚫린다.
- 해법: 비용 성장률을 1.07 수준까지 낮춰 «비용이 거의 선형인 구간»에 두면 L ∝ 골드 → 전투력 ∝ 골드²
  로 후반 성장이 살아난다. 대신 적 챕터 성장률을 내리고, 줄어든 체감 난이도는
  **웨이브 내 증가율(waveHp/waveDmg)** 로 되돌려 한 판 안의 압박을 유지했다.
- `goldKillBase`(챕터 무관 상수분)는 **초반 전용 레버**로 쓸 수 있음을 확인 — 0 → 0.8 로 올리면
  챕터1~5 만 눈에 띄게 쉬워지고 후반은 거의 그대로다 (실험3 셀 적합 47%→57%).
- 스윕 도구 `tools/sweep.js` 신설: `TUNE_OVERRIDE` 환경변수로 sim.js 기본 동작을 바꾸지 않고
